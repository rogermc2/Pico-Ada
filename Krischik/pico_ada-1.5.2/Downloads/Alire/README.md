Theses are files for the [Alire](https://alire.ada.dev/) package and build
manager and the preferred means of installation is to use Alire to build from
source.

# File types

**\*.tgz**
: Source Code. Don't download directly. Use [Alire](https://alire.ada.dev/)
  instead to download an build.

**\*.toml**
: Backup of the [Alire](https://alire.ada.dev/) build instruction. The main
  file is located in the [Alire
  repository](https://github.com/alire-project/alire-index/tree/stable-1.3.0/index/hp/pi-ada-tutorial).
